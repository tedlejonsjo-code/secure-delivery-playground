Utgå från ett enkelt scenario: ett företag använder e-post, Microsoft 365, mobiltelefoner och ett HR-system.
Identifiera 3 hot, 3 sårbarheter och 3 skyddsåtgärder. 

1. Hot: fhising mail, Sårbarhet: dålig medvetan om fhising bland personal. Åtgärd: Mer utbildning om fhising bland personal.
2. Hot: Ransomware. Sårbarhet: inte tillräckligt med patching. Säkerhetsåtgärd: Mer Patching
3. Hot: Misstag av personal. Sårbarhet: otillräcklig utbildning som leder till misstag eller väldigt slarvig personal. Åtgärd: Påminnelse om att vara mer försiktig eller sparka väldigtslarviga personal.
